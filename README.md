# resume-public

Public companion to the private resume repo. Serves the latest build of Hanson Wen's résumé at a stable URL for [hansonwen.dev](https://hansonwen.dev) to fetch, without exposing the private source.

Files here are auto-generated by a GitHub Actions workflow in `Hilo-Hilo/resume`. Don't hand-edit — changes will be overwritten on the next resume push.

## What's here

| File | Purpose |
|---|---|
| `website-resume.pdf` | Latest build of `website-resume.tex`. Replaced on every resume push. |
| `metadata.json` | `{ committedAt, date, sourceCommit }` — used by the website to name the download with the commit date. |

## Public URLs

- PDF: `https://raw.githubusercontent.com/Hilo-Hilo/resume-public/main/website-resume.pdf`
- Metadata: `https://raw.githubusercontent.com/Hilo-Hilo/resume-public/main/metadata.json`

## Pipeline

1. Push to `main` in `Hilo-Hilo/resume` (private).
2. Actions workflow `publish-website-resume.yml` compiles `website-resume.tex` with `xu-cheng/latex-action`.
3. Workflow pushes PDF + freshly-generated `metadata.json` to this repo via SSH deploy key (`PUBLIC_REPO_DEPLOY_KEY` secret).
4. `hansonwen.dev` fetches from the `raw.githubusercontent.com` URLs above on click.

Round-trip: ~90 seconds from push to live PDF.
